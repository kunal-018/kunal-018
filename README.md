## 🚀 Featured Projects

A few things I've built out of curiosity and the desire to solve practical problems.

### 💳 [Credit Card Optimizer](https://github.com/kunal-018/credit_card_optimizer)

A personal finance application designed to make managing multiple credit cards easier.

**Why I built it:** Managing multiple cards, billing cycles, payment deadlines, and interest-free periods can get confusing. I wanted one place to organize everything.

**Key Features:**
- Manage multiple credit cards.
- Track billing dates and payment due dates.
- Identify cards offering the longest interest-free period.
- Track upcoming payments and payment status.
- Receive automated payment reminders.
- Store data locally on the device.

**Built with:** Flutter • Dart • SQLite

### ❤️ [Brick Ball Love](https://github.com/kunal-018/Brick-Ball-Love)

A little experiment that combines coding, creativity, and a personal touch.

A romantic brick-breaker browser game where breaking all 40 bricks reveals a heartfelt surprise message.

**Features:**
- Interactive brick-breaker gameplay.
- Score tracking and keyboard controls.
- Random compliment messages.
- A surprise message unlocked after completing the game.

**Built with:** HTML • CSS • JavaScript
